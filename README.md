# Eggling

An offline pocket pixel pet for iOS and Android, built with Flutter. Your pet
lives on real time, needs care, and grows differently depending on how it is
raised. No account, ads, analytics or network use.

Eggling is an independent game. It is not affiliated with, or endorsed by, any
maker of virtual pet toys.

## Run

```bash
flutter pub get
```

```bash
flutter run --dart-define=DEV_TOOLS=true
```

`DEV_TOOLS` adds time-skip controls and the seed to Settings. They are also
present in any debug build.

## Check

flutter test
